# Publish William Shepelev's portfolio

The site is ready to publish as-is. It is a single-page portfolio, and `index.html` is the entry page.

## Before you begin

1. Download `William_Shepelev_Portfolio_Website.zip`.
2. Extract or unzip it.
3. Open the extracted folder. You should immediately see `index.html`, `styles.css`, `script.js`, `DEPLOY.md`, and the `assets` folder.
4. Do not upload only `index.html`. The other files and the complete `assets` folder are required.

## Option 1: GitHub Pages - recommended

GitHub Pages preserves the carousel, image viewer, animations, and contact links. With GitHub Free, the repository must be public.

### Create and upload the repository

1. Sign in at [github.com](https://github.com/).
2. Select the **+** menu in the upper-right corner and choose **New repository**.
3. Name it `william-shepelev-portfolio`.
4. Select **Public**.
5. Select **Create repository**.
6. On the new repository page, choose **uploading an existing file**. If that link is not shown, choose **Add file → Upload files**.
7. Drag everything from inside the extracted website folder into the upload area. `index.html` must be at the top level, not inside another folder.
8. Wait until every file finishes uploading.
9. Enter a commit message such as `Add portfolio website`.
10. Select **Commit changes**.

### Turn on GitHub Pages

1. In the repository, open **Settings**.
2. In the left sidebar, select **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set the branch to **main**.
5. Set the folder to **/ (root)**.
6. Select **Save**.
7. Wait a few minutes, then refresh the Pages settings. GitHub will show a public address similar to `https://your-username.github.io/william-shepelev-portfolio/`.
8. Open that address on both a computer and phone. The Work carousel should be the first page.

[Official GitHub Pages publishing guide](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

### Update the site later

1. Edit the local files.
2. Return to the GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload the changed files with the same names and confirm replacement.
5. Commit the changes. GitHub Pages will redeploy automatically.

## Option 2: Show the portfolio in Google Sites

For this multi-file website, the cleanest Google Sites workflow is to publish it with GitHub Pages first and then embed its public URL.

### Add it as a full-page portfolio

1. Complete the GitHub Pages steps above and copy the public portfolio URL.
2. Open your existing site at [sites.google.com](https://sites.google.com/).
3. In the right sidebar, select **Pages**.
4. Select the **+** button at the bottom.
5. Choose **Full page embed**.
6. Paste the GitHub Pages URL and select **Insert**.
7. Name the page **Work** or **Portfolio**.
8. In the Pages list, open that page's **More** menu and choose **Make homepage** if you want the embedded Work carousel to open first.
9. Select **Preview** and check both desktop and phone layouts.
10. Select **Publish**, confirm the public address and visibility, then select **Publish** again.

### Add it inside an existing Google Sites page

1. Open the page where the portfolio should appear.
2. Select **Insert → Embed**.
3. Choose **By URL**.
4. Paste the GitHub Pages URL and select **Insert**.
5. Stretch the embed to the full page width and increase its height.
6. Preview the site, then select **Publish**.

If Google Sites ever refuses to display the embedded page, add a button linking to the GitHub Pages address instead.

[Official Google Sites embedding guide](https://support.google.com/sites/answer/90569?hl=en)
